# Rust 文档资源生命周期

HTTP 层负责路径校验与响应；`src/render.rs` 负责工作队列、请求合并、仓库编译器和关闭流程；PDF / Typst 模块拥有原生文档。`src/resources.rs` 提供按字节计费的闲置 LRU、弱引用请求合并与取消标记。

## 所有权与并发

- 缓存持有文档的 `Arc`，渲染在短锁内取得快照，然后释放锁执行原生计算。正常淘汰跳过正在使用的快照；显式清空只释放缓存所有权，正在执行的任务仍可安全完成。
- 相同编译或页面请求在进入有界队列之前合并。每个订阅者独立取消；最后一个订阅者离开才释放共享 Future，取消尚未开始的任务，并向已开始的任务发送合作式取消标记。
- 队列使用 `Mutex<VecDeque<_>>` 与 `Condvar`，取消等待任务会立即移除任务并释放输入预算与队列名额，不需要等待前面的原生任务完成。运行中的任务继续保留预算直到执行结束。
- 原生编译和渲染不强行中断。发布结果前检查取消与缓存代际/文档身份，避免过时工作重新填充已经清空的缓存。
- Typst 编译串行，等待队列 32 项，输入与运行中的源码合计最多 32 MiB（按 UTF-16 等效估算）。页面执行并发为 2，等待队列 32 项。仓库编译器的创建和淘汰也在工作线程中执行。
- 关闭服务时先结束 SSE 长连接，停止接收任务，再排空已接收任务并 join 工作线程，最后在阻塞线程中释放文档、页面、字体和 Comemo 缓存。维护定时任务在服务退出时取消；Unix 同时响应 SIGINT 和 SIGTERM。

## 缓存与租约

| 资源 | 预算与回收 |
| --- | --- |
| Typst SVG 与链接 | 全服务共享 64 页、16 MiB；闲置 5 分钟过期 |
| PDF SVG | 全服务共享 64 页、8 MiB；闲置 1 分钟过期 |
| Typst 布局 | 每仓库 3 文档数量目标；最新活跃修订与正在使用的快照保留；非活跃文档分别按最后使用时间在 15 分钟后回收 |
| Typst 源码快照 | 每仓库最多 16 MiB；按路径、主题最多保留两个修订；旧修订有 15 秒切换宽限，第三个修订替换更旧的未使用修订 |
| 仓库编译器 | 数量目标 3；活跃或在用时允许超过目标，最多 8 个 |
| PDF 文档 | 数量目标 3；活跃、在用及宽限期文档受保护；最多 32 个修订、128 MiB 输入字节，单文件最多 64 MiB |
| PDF 旧修订 | 60 秒切换宽限，每文件保留最新与一个旧修订；更旧的在用快照由 `Arc` 保活 |

租约继续使用浏览器已有的 30 秒心跳、90 秒失联解除协议，同时保护 PDF 与 Typst。路径是否活跃与页面缓存是否命中相互独立：租约保留文档，不永久保留所有渲染页。后台维护每分钟执行，实际释放时间受维护间隔与正在执行的任务影响。

Typst 缓存按规范化路径、主题及源码的 128 位内容摘要直接查找，并检查源码相等。缓存命中会校验本次编译实际读取的 project/package 文件内容，以及 `datetime.today` 使用的日期；import、include、图片、数据文件变化或删除会使编译失效。内容校验能识别同大小、恢复 mtime 的修改。已有页面 ID 始终代表其编译时快照，过期返回 410，并保留仓库归属校验。

PDF 的页面键使用类型化的路径、修订和页码，不拼接字符串。携带旧修订的页面请求在快照仍处于宽限期时读取旧快照；快照过期且磁盘版本已变化时返回 410。硬预算不足时拒绝新增加载，不为接收新文件而强制回收活跃文档。

这些预算约束应用持有的源码与编码结果，不是 RSS 硬上限。PDF 解码数据、Typst 布局/字体、Comemo、渲染临时内存和分配器保留都需要单独观察。性能基准分别报告完整热编译与缓存命中，不能通过缓存缩小或命中耗时替代完整编译性能结论。

## 验证

`cargo test --release --locked` 覆盖租约保护、超预算拒绝、同请求合并、订阅者取消、依赖失效、跨仓库页面隔离、旧修订回收、独立闲置回收、快照保活和关闭后拒绝请求。原生性能基准用法见 `tests/benchmark/rust-backend.md`。

本机 Linux release 的一次小夹具观测：616 字节 Typst 文档完整热编译 p50 为 0.645 ms，应用缓存命中 p50 为 0.00454 ms（各 15 次）。128 轮、8 个活跃文档的编辑/切换场景中，Typst 持有量稳定在 32 个布局（含两种主题和过渡修订），PDF 稳定在 16 个修订；最终显式释放后，两者的文档、源码及页面缓存计数全部为零。RSS 从第 32 轮的 35,424 KiB 到第 128 轮的 35,568 KiB，释放后为 26,096 KiB。这是功能与资源预算的代表性 smoke 观测，不能代替大型文档或长期 RSS 回归。

本轮原生全量回归与两个显式性能场景通过，前端生产构建通过。JS 全量回归另发现 `library_search.test.mjs` 的搜索范围预期失败、`typst_worker.test.mjs` 的未完成 Promise 导致事件循环提前退出；本次 Rust 资源管理未修改这两条 JS 实现路径。`server_routes.test.mjs` 在沙箱内因监听端口被拒绝，沙箱外重跑通过。
